# حسبنا كتاب الله — أداة المناظرة: القرآن وحده

تطبيق Flutter لـ **Android** و**Windows**، يعمل بدون إنترنت، لتحضير المناظرات مع من يقدّمون الروايات على كتاب الله.

## المحتوى (v2)
| القسم | العدد |
|---|---|
| مراجع الأحاديث (13 صنفاً) | 200 |
| التناقضات (حديث ضد حديث / حديث ضد آية) | 70 |
| سلاسل الحجج (ربط الأحداث حتى الخلاصة) | 32 |
| الاعتراضات والردود | 60 |
| حجج القرآن وحده | 20 |
| القرآن الكريم | 6236 آية |
| صحيحا البخاري ومسلم كاملان للبحث | +14000 رواية |

## الميزات
- **وضع المناظرة**: بحث واحد في كل شيء، نتائج مرتّبة حسب القوة، ورقم الآية مباشرة.
- **التناقضات** جنباً إلى جنب، و**السلاسل** بخط زمني مرقّم حتى الخلاصة الإلزامية.
- **بطاقة صورة** لكل رد أو تناقض أو سلسلة أو حديث للنشر في وسائل التواصل.
- **المفضلة، ملاحظاتي، حججي الخاصة**، و**وضع التدريب** (البرنامج يلعب دور المحاور).
- **«أين استُعملت هذه الآية»** في قارئ القرآن.
- **تحديث المحتوى من الإنترنت** (رابط قابل للتعديل في الإعدادات).

## التحقق من المصادر
- كل حديث مستخرج آلياً من قواعد sunnah.com بالرقم، مع **عبارة مفتاحية** يتحقق السكربت `tool/build_data.py` من وجودها في النص المستخرج؛ إن لم توجد يتوقف البناء.
- لكل حديث رابطان: sunnah.com بالرقم، والدرر السنية بالنص.
- أحكام الألباني على أحاديث السنن معروضة كما هي (ومنها الضعيف).

## البناء
كل `push` يبني تلقائياً عبر GitHub Actions ويُنشر في **Releases**:
`hasbuna-android.apk` و `hasbuna-windows.zip`.

## تعديل المحتوى
`tool/content_src.py` ثم `python3 tool/build_data.py assets/data` (يحتاج نسخاً محلية من مستودعي `fawazahmed0/hadith-api` و`AhmedBaset/hadith-json`، المسارات في `tool/hs.py`).
