# مُناظِر — القرآن وحده

أداة لتحضير المناظرات ودعمها في مواجهة من يقدّمون الروايات على كتاب الله.
تطبيق Flutter يعمل على **Android** و**Windows**، وبدون إنترنت.

## المحتوى
| القسم | الوصف |
|---|---|
| **وضع المناظرة** | بحث فوري واحد في الردود والأحاديث والحجج والآيات، أو بكتابة رقم الآية (`6:38` أو `البقرة 255`). زر نسخ جاهز للصق في النقاش. |
| **الاعتراضات والردود** | 22 اعتراضاً معروفاً لأهل الحديث، مع الرد والأدلة القرآنية. |
| **مراجع الأحاديث** | 37 حديثاً مصنّفة: في الله، في النبي، في الأنبياء، في أزواج النبي، في القرآن وحفظه، ما يناقض القرآن، ما يخالف العقل، وأحاديث يُحتج بها على أهل الحديث. النص الكامل، المصدر، الرقم، والآيات المعارضة. |
| **القرآن الكريم** | المصحف كاملاً (6236 آية، رواية حفص)، بحث بالكلمة أو السورة أو الرقم. |
| **الحجج** | 10 حجج أساسية لكفاية القرآن. |

## التحميل
كل `push` على الفرع `main` يبني تلقائياً (GitHub Actions):
- `munazir-android.apk` لهاتف Android
- `munazir-windows.zip` للحاسوب (فكّ الضغط ثم شغّل `munazir.exe`)

الملفات في تبويب **Releases** في المستودع.

## المصادر والتحقق
- نص القرآن: [Tanzil](https://tanzil.net), النص البسيط المشكول (Hafs)، بدون أي تعديل.
- نصوص الأحاديث: مستخرجة آلياً من [sunnah.com](https://sunnah.com) عبر قاعدة [hadith-json](https://github.com/AhmedBaset/hadith-json).
- أرقام الأحاديث بترقيم sunnah.com، ولكل حديث رابط للتحقق.

## التطوير
```bash
flutter create --platforms=android,windows --org com.munazir --project-name munazir .
flutter run
```
لتعديل المحتوى: عدّل `tool/content_src.py` ثم أعد توليد `assets/data/content.json`:
```bash
HADITH_DIR=…/hadith-json/db/by_book/the_9_books/ TANZIL_DIR=…/quran-json/data/tanzil/ python3 tool/build_data.py write
```
